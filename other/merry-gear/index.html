How to Control

Input Action
Arrow Keys: Move/Cycle Inventory (L/R Only)
Shift (Hold): Open Inventory
Enter/Shift: Confirm
Crtl: Use Item
Ctrl (Hold): Skip Codec
Ctrl (Against Wall): Knock
F2: Soft Reset
Alt+Enter: Windowed/Full Screen Cycle
H (Main Menu): Debug Menu (?)
Hitting Enter Begins a New Game w/ Main Menu Music
