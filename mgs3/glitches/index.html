The Fury 2nd Controller Instant Kill Glitch

If a 2nd controller is present and you're playing the NTSC-U MGS3 Sneake Eater release on PS2, pressing X or O drains the Fury's health or stamina bar. Mash either buttons and the fight can start and almost instantly be over. Assumingly this is a dev feature that got removed in subsequent releases of the game.
