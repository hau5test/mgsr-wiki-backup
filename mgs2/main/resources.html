MGS2 Resources

Tools

  • V's Fix for PC: This is another way to make the PC version more usable on modern PC's. Fixes the launcher and makes it more user friendly. Includes the widescreen fix, texture fixes, and better controller support.
  • bmn's MGS2 Substance PC tools: Tools such as the following can be downloaded here:
    • Autosplitter
    • Caution Patch
    • Overlay Patch
    • Trainer
    • Randomizer
  • Autosplitter for PC (Old Version): Autosplitter that is 95% stable for use with LiveSplit. You must run LiveSplit as administrator for this to work.
  • Autosplitter for PC (New Version by bmn): Very stable and includes lot of extras for ASL VAR Viewer, such as Alerts, Kills, # of Rolls/Cartwheels and much more along with pre-made splits. You must run LiveSplit as administrator

Saves

  • All PC Saves, All Difficulties: The ultimate save pack for PC. Contains saves for all difficulties and for a variety of situations. Radar off, quick change on Previous and name set to MGSR in all saves.
  • Updated Very Easy only savepack: An updated version of the regular Very Easy savepack for PC. It contains saves for all boss fights (including lethal/non lethal Fatman),saves for the tough/complex areas or for important starting points and saves for different scenarios. Radar Type 1 , quick change on Previous and name set to MGSR.
  • Completed Snake Tales Save for NG+ Runs (PC): All Snake Tales completed for PC version to be able to do NG+ runs.
  • All PS3 Saves: All saves for all difficulties for use on PS3. You will not be able to collect trophies, overwrite the save or make a new save from loading one of these saves due to copy protection. For use with the Japanese version.
  • MGS2 PC Developer Save: For use with PC. Replace the scenerio.gcx file with the provided one in the following folder of your MGS2 install: \cdrom.img\stage\select. Then you'll be able to boot the game and directly do your selections to start the game.
  • MGS2 & MGS3 PS3 Developer Save: For use with PS3, US version.
